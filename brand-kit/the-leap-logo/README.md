# The Leap logo kit

All files are SVG vectors with the lettering converted to outlines, so they
open the same in Illustrator, Figma, Canva, Inkscape or a browser without
needing the Sora font installed. Scale them to any size.

## Folders

| Folder | Colour | Use on |
|---|---|---|
| `orange/` | Brand orange `#FF7A00` | White, cream or light backgrounds |
| `black/` | Black `#000000` | Light backgrounds, single-colour print, stamps, documents |
| `white/` | White `#FFFFFF` | Dark backgrounds and photos |
| `full-color/` | Orange tile, cream arc, charcoal or white lettering | The main logo wherever full colour is possible |

## Files in each colour folder

- `the-leap-logo-horizontal.svg`: icon + "the leap" side by side. The default logo.
- `the-leap-logo-stacked.svg`: icon above "the leap", for square spaces.
- `the-leap-icon.svg`: the rounded tile with the arc cut out (see-through).
  App-icon shape, profile pictures, favicons.
- `the-leap-mark.svg`: the arc and dot alone, no tile. Watermarks, embroidery, small marks.
- `the-leap-wordmark.svg`: "the leap" lettering alone.

## Simple rules

- Keep clear space around the logo of at least half the icon's height.
- Don't stretch, rotate, recolour outside these colours, or add effects.
- Smallest size: icon 16 px on screen / 6 mm in print; horizontal logo 100 px wide / 25 mm.

The kit is generated from the same geometry as the app's mark
(`src/components/brand-mark.tsx`). Typeface: Sora Bold.
