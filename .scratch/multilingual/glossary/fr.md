# French (fr) glossary

Register: **tu** throughout (an evangelical discipleship app speaking personally). Bible tradition: Louis Segond 1910. International French (francophone Africa and Europe), no France-only idioms.

## Product terms

| English | French | Rationale |
|---|---|---|
| Connect (movement) | Communion | "Se connecter" means *log in* in French apps, so it can't be the tab name. "Communion" echoes Acts 2:42 LSG ("la communion fraternelle") and fits "I belong" (J'ai ma place). Reviewers: possible Lord's Supper connotation; alternative "Lien". |
| Commit (movement) | S'engager | Verb, like the English. The noun "Engagement" is reserved for Commitment. |
| Evolve (movement) | Grandir | "Évoluer" sounds secular and technical; "grandir" is the usual word for spiritual growth (and matches sw "Kua"). |
| Engage (movement + loop step) | Agir | "Engager" is taken by Commit; "Agir" is short and fits serve/give/invite. |
| Multiply | Multiplier | |
| Formation Journey / Journey | Parcours de formation / Parcours | "Voyage" is too literal. |
| Session | Séance | |
| Scripture (loop step, section) | Écriture | As in "l'Écriture" (2 Tim 3:16). |
| Message | Message | |
| Explore | Explorer | |
| Reflect | Réfléchir | "Méditer" avoided so it doesn't clash with Daily Devotion. |
| Pray | Prier | |
| Next Step | Prochain pas | "Pas" keeps the walking image ("faire un pas"). "First Leap" is also rendered "premier pas"; "Next Leap" is "Prochaine étape". |
| Daily Devotion / devotion | Méditation quotidienne / méditation | The usual francophone evangelical term. "Dévotion" sounds Catholic and pietistic. |
| Reflection (devotion section) | Réflexion | |
| Practice | Mise en pratique | Echoes James 1:22 ("mettez en pratique"). |
| Commitment | Engagement | |
| Prayer Room | Salle de prière | |
| Prayer Request | Sujet de prière | The standard expression in francophone churches. |
| Testimony | Témoignage | |
| Community | Communauté | |
| Announcement | Annonce | |
| Leap Companion | Compagnon Leap | Following the sw principle: "Leap" stays, "Companion" is translated. |
