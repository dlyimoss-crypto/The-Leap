# Spanish (es) glossary

Neutral international Spanish, informal "tú" throughout. Theological vocabulary follows the Reina-Valera tradition.

## Product terms

| English | Spanish | Rationale |
|---|---|---|
| Connect (movement / tab) | Conecta | Imperative, short, matches "I belong" (Pertenezco). |
| Commit (movement / tab) | Compromiso | A noun, as Swahili used ("Ahadi"). "Comprométete" (12 chars) is too long for a nav tab. The sub-line stays "Elijo el camino de Cristo." |
| Evolve (movement / tab) | Crece | "Evoluciona" suggests biological evolution. "Crece" matches the tagline "Estoy creciendo" and Swahili "Kua". |
| Engage (movement / tab) | Participa | "Involúcrate" is too long for a tab. Used in the heading "Involúcrate. Participa. Marca la diferencia." |
| Multiply | Multiplica | |
