# German (de) glossary

Register: informal "du" throughout (lowercase for the user). In prayer text addressed to God, "Du/Dich/Dir" is capitalised as a reverent convention (mirrors the English "You"). Bible tradition: Luther 1912.

## Product terms

| English | German | Rationale |
|---|---|---|
| Connect | Verbinden | Movements are verbs so the four nav tabs read as one set. |
| Commit | Entscheiden | Subheading "Ich wähle den Weg Christi." "Verpflichten" sounded legalistic and is too long for a tab; "Hingabe" breaks the verb pattern. |
| Evolve | Wachsen | "I am becoming" → "Ich wachse." Growth is the established German discipleship image. |
| Engage | Wirken | Short, and carries "living out a purpose beyond myself" (cf. "Gottes Wirken"). |
| Multiply | Weitergeben | "Multiplizieren" exists in German discipleship jargon but sounds technical; "Weitergeben" = passing faith on. |
| Formation Journey | Glaubensreise (short: Reise) | "Weg" avoided to keep it distinct from "der Weg Christi". |
| Session | Einheit | Standard for a unit in a course/study. |
| Scripture (Loop step) | Bibeltext | Section/tab headings use "Bibel"; "Bibelstelle" = Scripture reference. |
| Message | Impuls | Established German devotional term for a short encouraging thought. |
| Explore | Entdecken | |
| Reflect | Nachdenken | "Reflektieren" sounds academic. |
| Pray | Beten | |
| Next Step | Nächster Schritt | |
| Engage (Loop step) | Wirken | Same as the movement. |
| Leap (as in "your first Leap") | Sprung | "Wage deinen ersten Sprung"; echoes "Glaubenssprung". |
| Daily Devotion | Tagesandacht (short: Andacht) | |
| Practice | Umsetzung | Practical application, not "Übung" (which suggests exercise/drill). |
| Commitment | Vorsatz | A self-set weekly intention; "Verpflichtung" is legalistic. |
| Prayer Room | Gebetsraum | |
| Prayer Request | Gebetsanliegen | Prayer points (announcements) = "Gebetspunkte", to keep them distinct. |
| Testimony | Zeugnis | |
| Community | Gemeinschaft | "Gemeinde" is reserved for local churches. |
| Church (local) | Gemeinde | Evangelical usage; "Kirche" sounds like a building or a state church. |
| Announcement | Ankündigung | Kind "General" = "Allgemein" / dashboard "Ankündigung". |
| Leap Companion | Leap-Begleiter (short: Begleiter) | Brand word "Leap" kept, as Swahili did. |
| Answered (prayer) | erhört | Standard church usage for answered prayer. |
