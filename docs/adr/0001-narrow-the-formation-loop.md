# Narrow the Formation Loop to Scripture → Message → Explore → Reflect → Pray

Formation Journey Sessions previously moved through Scripture → Explore → Reflect → Pray → Practice → Connect → Next Step → Engage — six content steps before a person moved on. The product goal for a Journey is depth on one thing per day ("eating an elephant one piece at a time"), and six steps per Session worked against that: too much for one sitting, and it invited authors to spread a day's teaching thin across steps instead of landing one thought well.

We're narrowing the Formation Loop to Scripture → Message → Explore → Reflect → Pray, adding a new Message step (a short, plain-language passage unpacking the Scripture) and dropping Practice and Connect as Session steps.

Practice survives as a concept, but only on Daily Devotion (`/evolve/devotion`) — a separate, admin-published daily content feature that was never part of a Formation Journey. Connect had no independent meaning outside the old Formation Loop and is retired as a Session concept entirely; it is unrelated to the CONNECT Core Movement (the `/connect` church-finder area), which is untouched by this change.

This is scoped to Formation Journey Sessions only — Daily Devotion's structure, and every other Core Movement, is unaffected.
